# Acerca de este archivo
El archivo contiene 4600 registros completos con 18 características distintas, ofreciendo una visión detallada del mercado inmobiliario del estado de Washington en 44 ciudades y 77 códigos postales. El conjunto de datos está completamente libre de valores faltantes o nulos, lo que garantiza su disponibilidad inmediata para el análisis exploratorio de datos (AED) y las tareas de aprendizaje automático sin necesidad de imputación compleja. Las variables clave incluyen la valoración de la propiedad (precio), las dimensiones estructurales (p. ej., superficie habitable, dormitorios, pisos), las calificaciones de estado, los datos históricos (año de construcción, año de renovación) y los identificadores geográficos detallados. Además, el archivo ha sido preprocesado para eliminar datos geográficos redundantes e incluye una nueva métrica de precio por pie cuadrado para agilizar instantáneamente las evaluaciones y el modelado de precios.
